# Landing Seoul preview

User requested the furnished Seoul home on the landing page. The preview loads
the same compressed GLB as `/demos/seoul-apartment`, through the private asset
service, using vendored Three.js and meshoptimizer. No dataset media is committed.
Original furniture/materials and approximate source dimensions are retained.
No extra floor plane is added. Rotation, drag, keyboard, shared Pause, reduced
motion and visibility controls remain. The main sample CTA opens Seoul.
See `docs/SEOUL-SAMPLE.md` for source provenance and derivative repairs.
