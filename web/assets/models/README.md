# Landing building illustration

`sunrise-office.glb` is an unchanged copy of the user's local
`3D_Building/frontend/public/artifacts/sunrise-office-tower-5f-6r.glb`.
Used on Thai's direct instruction to add a 3D building to the landing, following the previous instruction to reference that project.

This is a pre-existing procedural illustration generated by that project's
`builder/procedural.py` with trimesh, not reconstruction from the linked sample home's photos, not a surveyed building. Named geometry: floorplates, partitions, glazing, mullions, roof, canopy. Source GLB is 167588 bytes; includes geometry/materials, no external textures or URIs. No user panorama/photo is copied into this asset.

`building-preview.js` is a new Codex-assisted native WebGL renderer, scoped to this supplied untextured triangle GLB. The oversized presentation ground slab is omitted for framing; building geometry is unchanged. It honors baked/matrix node transforms, colors and translucent glass, computes face normals and sorts transparent triangles. It is not a general-purpose glTF loader. No added dependencies, paid generation or provider upload. Pre-existing asset predates this change; competition H0 not verified.
